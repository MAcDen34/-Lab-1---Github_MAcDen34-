# Grade Generator Calculator & Organizer

## Project Overview
This project consists of two parts:
1. **Python Grade Generator** - Interactive application for calculating student grades
2. **Shell Script Organizer** - Bash script for archiving CSV files

## Files Structure
project/
├── grade-generator.py # Python grade calculator
├── organizer.sh # Bash file organizer
├── README.md # Project documentation
└── archive/ # Created by organizer.sh for archived files

**Python Grade Generator**
Calculates the inputed grades
Checks whether the assignment enter is (FA or SA) 
Then determines whether the assignment has been failed or passed  
And gives the GPA score and status
Thus then records are saved and store as .csv files

2. **Shell Script Organizer**
Archives the stored record in the generated archieve file as csv files 
Created  a log file for the stored data with a timestamp of each interaction by user
