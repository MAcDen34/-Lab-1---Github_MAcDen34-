# Grade Generator Calculator & Organizer

## Project Overview
This project consists of two parts:
1. **Python Grade Generator** - Interactive application for calculating student grades
2. **Shell Script Organizer** - Bash script for archiving CSV files

## Files Structure
project/
├── grade-generator.py # Python grade calculator
├── organizer.sh # Bash file organizer
├── README.md # Project documentation
└── archive/ # Created by organizer.sh for archived files
